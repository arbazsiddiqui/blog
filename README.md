# arbazsiddiqui.me

Personal site. Astro, deployed to Cloudflare Pages via GitHub Actions on push to master.

- `src/pages` — routes (home, projects, about, blog, one page per project)
- `src/content/blog` — articles (markdown, slugs preserved from the 2020 site)
- `public/` — static assets, legal pages for the iOS/Android apps, redirects
- Build: `npm run build` (Node ≥ 22.12) · Preview: `npm run preview`
